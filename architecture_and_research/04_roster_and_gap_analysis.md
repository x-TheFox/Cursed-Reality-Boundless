## E. Porting implication

NPCs in JJA run the same move functions as players (`execute as @e[type=ds:student_gojo2]… run function limitless/limitless5`). The Java port keeps that: abilities are written once against an `AbilityUser` (player or mob), and each NPC's brain just chooses which ability to start.
